# HTTP API

## Общие сведения

Бэкенд предоставляет REST-like HTTP API.

Базовый путь:

```text
/api
```

Формат обмена данными:

```text
Content-Type: application/json
```

Все даты в текущей версии не используются.

---

## Системные эндпоинты

### Проверка работоспособности

```text
GET /healthz
```

Ответ:

```json
{
  "status": "ok"
}
```

Код ответа:

```text
200 OK
```

---

## Формат ошибок

При ошибке сервер возвращает JSON-объект.

Базовый формат:

```json
{
  "message": "человекочитаемое сообщение об ошибке",
  "code": "machine_readable_code"
}
```

Пример:

```json
{
  "message": "product with this name already exists",
  "code": "conflict"
}
```

Для ошибок валидации допускается формат:

```json
{
  "message": "validation failed",
  "code": "validation_error",
  "details": {
    "name": [
      "name is required"
    ]
  }
}
```

---

## Коды состояния

| Код | Значение |
|---|---|
| 200 | Операция выполнена успешно |
| 201 | Ресурс создан |
| 204 | Ресурс удалён или ответ без тела |
| 400 | Неверный запрос или ошибка валидации |
| 404 | Ресурс не найден |
| 409 | Конфликт, например нарушение уникальности |
| 500 | Внутренняя ошибка сервера |

## Товары

### Объект товара

```json
{
  "id": 1,
  "name": "Ноутбук",
  "price": 10000000
}
```

Поля:

| Поле | Тип | Описание |
|---|---:|---|
| id | integer | Идентификатор товара |
| name | string | Уникальное название товара |
| price | integer | Цена в минимальных единицах валюты |

---

### Получить список товаров

```text
GET /api/products
```

Ответ:

```json
[
  {
    "id": 1,
    "name": "Ноутбук",
    "price": 10000000
  },
  {
    "id": 2,
    "name": "Мышь",
    "price": 150000
  }
]
```

Код ответа:

```text
200 OK
```

Если товаров нет, возвращается пустой массив:

```json
[]
```

---

### Получить товар по идентификатору

```text
GET /api/products/{id}
```

Пример:

```text
GET /api/products/1
```

Ответ:

```json
{
  "id": 1,
  "name": "Ноутбук",
  "price": 10000000
}
```

Коды ответов:

```text
200 OK
404 Not Found
```

---

### Создать товар

```text
POST /api/products
```

Тело запроса:

```json
{
  "name": "Ноутбук",
  "price": 10000000
}
```

Валидация:

```text
name: required, length 1..255
price: required, integer >= 0
```

Ответ:

```json
{
  "id": 1,
  "name": "Ноутбук",
  "price": 10000000
}
```

Коды ответов:

```text
201 Created
400 Bad Request
409 Conflict
500 Internal Server Error
```

Код `409` возвращается, если товар с таким названием уже существует.

---

### Обновить товар

```text
PUT /api/products/{id}
```

Тело запроса:

```json
{
  "name": "Игровой ноутбук",
  "price": 12000000
}
```

Обновление полное.

Частичное обновление через `PATCH` в текущей версии не реализуется.

Ответ:

```json
{
  "id": 1,
  "name": "Игровой ноутбук",
  "price": 12000000
}
```

Коды ответов:

```text
200 OK
400 Bad Request
404 Not Found
409 Conflict
500 Internal Server Error
```

Код `409` возвращается, если новое название уже занято другим товаром.

---

### Удалить товар

```text
DELETE /api/products/{id}
```

Коды ответов:

```text
204 No Content
404 Not Found
409 Conflict
500 Internal Server Error
```

Код `409` возвращается, если товар используется хотя бы в одном заказе.

## Заказы

### Объект заказа

```json
{
  "id": 1,
  "number": "ORD-0001",
  "deliveryAddress": "Москва, ул. Пушкина, д. 1",
  "products": [
    {
      "id": 1,
      "name": "Ноутбук",
      "price": 10000000
    },
    {
      "id": 2,
      "name": "Мышь",
      "price": 150000
    }
  ]
}
```

Поля:

| Поле | Тип | Описание |
|---|---:|---|
| id | integer | Идентификатор заказа |
| number | string | Уникальный номер заказа |
| deliveryAddress | string | Адрес доставки |
| products | array | Список товаров в заказе |

Порядок товаров в ответе:

```text
сортировка по id товара
```

---

200 OK

```json
[]

    {

```

---

### Создать заказ

```text
POST /api/orders
```

Тело запроса:

```json
{
  "number": "ORD-0001",
  "deliveryAddress": "Москва, ул. Пушкина, д. 1",
  "productIds": [1, 2]
}
```

Валидация:

```text
number: required, length 1..64
deliveryAddress: required, length 1..500
productIds: required, min 1, unique elements
```

Все товары из `productIds` должны существовать.

Ответ:

```json
{
  "id": 1,
  "number": "ORD-0001",
  "deliveryAddress": "Москва, ул. Пушкина, д. 1",
  "products": [
    {
      "id": 1,
      "name": "Ноутбук",
      "price": 10000000
    },
    {
      "id": 2,
      "name": "Мышь",
      "price": 150000
    }
  ]
}
```

Коды ответов:

```text
201 Created
400 Bad Request
404 Not Found
409 Conflict
500 Internal Server Error
```

Код `404` возвращается, если хотя бы один товар из списка не найден.

Код `409` возвращается, если заказ с таким номером уже существует.

---

### Обновить заказ

```text
PUT /api/orders/{id}
```

Тело запроса:

```json
{
  "number": "ORD-0002",
  "deliveryAddress": "Санкт-Петербург, Невский проспект, д. 10",
  "productIds": [2, 3]
}
```

Обновление полное.

Список товаров в заказе заменяется на переданный `productIds`.

Ответ:

```json
{
  "id": 1,
  "number": "ORD-0002",
  "deliveryAddress": "Санкт-Петербург, Невский проспект, д. 10",
  "products": [
    {
      "id": 2,
      "name": "Мышь",
      "price": 150000
    },
    {
      "id": 3,
      "name": "Клавиатура",
      "price": 300000
    }
  ]
}
```

Коды ответов:

```text
200 OK
400 Bad Request
404 Not Found
409 Conflict
500 Internal Server Error
```

Код `404` возвращается, если заказ не найден или хотя бы один товар не найден.

Код `409` возвращается, если новый номер заказа уже занят другим заказом.

---

### Удалить заказ

```text
DELETE /api/orders/{id}
```

Коды ответов:

```text
204 No Content
404 Not Found
500 Internal Server Error
```

При удалении заказа связи с товарами в таблице `order_products`
удаляются автоматически.

---

## Поведение при нарушении уникальности

### Товар

Если созданный или обновлённый товар имеет имя, которое уже используется:

```text
409 Conflict
```

### Заказ

Если созданный или обновлённый заказ имеет номер, который уже используется:

```text
409 Conflict
```

---

## Поведение при удалении товара

Если товар не используется ни в одном заказе:

```text
204 No Content
```

Если товар используется хотя бы в одном заказе:

```text
409 Conflict
```

---

## Версияирование API

На текущем этапе версияирование не используется.

Все эндпоинты доступны без префикса версии:

```text
/api
```

---

## Что не входит в текущую версию

- количество товаров в заказе;
- пагинация списков;
- сортировка;
- фильтрация;
- поиск;
- авторизация;
- история изменений;
- мягкое удаление;
- частичное обновление через PATCH.
